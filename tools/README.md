# Offline geodata tools

This directory will contain reproducible acquisition/conversion tools for DortmundGameMap.

Planned order:
1. source downloader / manifest
2. EPSG:25832 normalization
3. 256 m tiler
4. DGM1 terrain + collision builder
5. CityGML LoD2 → per-cell GLB conversion
6. ALKIS QA/collision footprints
7. OSM road graph extraction
8. orthophoto mobile texture pipeline
9. world_manifest.json generator
